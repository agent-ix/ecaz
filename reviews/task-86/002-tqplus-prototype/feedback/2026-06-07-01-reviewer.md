## Measurement evidence — scoped probe only

`tqplus-probe.log` reports MAE/RMSE on a synthetic 1536-d
anisotropic corpus (train=192, candidates=96, queries=16):
baseline_mae=0.0264 vs tqplus_mae=0.0034 (−86.97%).

**This is not the §Required Evidence set.** Missing:
- recall@10 on canonical corpora
- p50/p95/p99 latency
- per-vector stored bytes accounting
- scorer/prep timing under release profile

The request honestly notes "not yet production evidence" —
that's the saving grace. As a probe to motivate further work,
the result is supportive of TQ+ calibration as a priority
hypothesis. As an AM-rollout signal, it is insufficient.

## Substantive concerns

1. **`fit_tqplus_calibration_for_test` integrates `beta_pdf`
   with 20,001 trapezoid points inside every call.** For
   `dim=1536` that is 30M+ `beta_pdf` calls per fit.
   Acceptable for a probe; **must not survive into bench/
   prod path without memoization keyed by `original_dim`**.
   Flag for follow-up before any release build cites this.

2. **`renorm = norm / reconstructed_inner` formula has no
   docstring.** Field is named `renorm` on the encoded struct
   with no comment on its theoretical basis. Slice 003 split
   the orthogonality cleanly and found unrenorm BEATS renorm
   (003 review) — document the formula's intended use or
   delete it before promoting.

3. **`renorm` divide-by-zero guard returns `0.0`.** Silent
   failure mode on degenerate vectors. Not blocking for a
   probe; must surface (NOTICE, error, or explicit recovery)
   before any production scorer.

## Required to advance past probe stage

Per Task 86 §Gates and §Required Evidence, before TQ+
calibration is cited as an AM candidate:

1. Drop `renorm` from the index-level prototype path (003's
   own conclusion). Keep field only behind an explicit
   second-experiment switch.
2. Memoize `canonical_beta_quantiles_for_tqplus` keyed by
   `original_dim`.
3. Move from score-error probe to **recall@10 on a real
   fixture via `ecaz bench suite`** under release profile,
   on a canonical corpus (real10k or similar).
4. Document the `renorm` formula or remove the field.

These don't gate the probe itself — they gate advancing past
probe.
