## Findings

### P1 - The required NFR-020 fault taxonomy is not complete

NFR-020 names the default fault taxonomy: connection reset, remote timeout, remote backend termination, epoch mismatch, missing record, placement drift, network partition, hop-round failure mid-beam, mid-insert failure, and mid-delete failure (`spec/non-functional/NFR-020-distann-fault-behavior.md:17`). The packet still omits `remote_statement_timeout`, `hop_round_failure_mid_beam`, fixture-level `missing_node_record`, mid-insert, and mid-delete. The manifest also lists those omissions as follow-up work (`reviews/task-165/013-fault-matrix/artifacts/manifest.md:28`).

Representative coverage is useful, but the task's acceptance criterion is 100% drill pass across the taxonomy. This cannot close TC-042 or Task 165.

### P2 - Several drills do not assert "error-or-identical-to-baseline" mechanically

The helper treats any output containing `ERROR`, `EC_INTERNAL`, or `could not connect` as pass (`crates/ecaz-cli/src/commands/dev/distann_multicluster.rs:553`), so the matrix does not verify the expected machine-readable class per drill. The no-false-reject drill passes if the query does not error and the output contains a newline (`crates/ecaz-cli/src/commands/dev/distann_multicluster.rs:344`); it does not compare returned ids/order to the baseline. NFR-020 requires either an error or a correct complete result, and its verification says each drill asserts identical results versus the fault-free run (`spec/non-functional/NFR-020-distann-fault-behavior.md:41`).

Please store the baseline rows with ordinality and make every non-error arm compare ids/order. For error arms, assert the expected SQLSTATE/error class for that injection, not only that some error text was printed.

### P3 - Packet provenance is incomplete

The manifest records `head SHA: (fault-matrix commit on task-165-ec-distann-m3)` instead of an exact SHA (`reviews/task-165/013-fault-matrix/artifacts/manifest.md:3`). It also omits `placement_drift` from the key result lines even though the summary log contains it. Please pin the exact commit and keep the manifest's cited result lines aligned with the artifact.
