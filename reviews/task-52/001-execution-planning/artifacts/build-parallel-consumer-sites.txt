Wrappers proposed (Task-52 scope)
---------------------------------
1. `EcHnswParallelBuildSharedView<'a>`  — single view, both phases.
   Methods:
     - safe constructor pair: `unsafe fn from_raw(*mut EcHnswParallelBuildSharedHeader)`
       (DSM lifetime contract); safe `header()`, `participant_count()`,
       `requested_workers()`, etc.
     - `record_workers_done(&self, scanned_delta, encoded_delta) -> ()` —
       absorbs the entire SpinLockAcquire + mutate + SpinLockRelease + Signal
       compound into one safe method. Documented as the "worker-done
       publication" sequence.
     - `init_synchronization(&mut self)` — safe wrapper for the leader's
       SpinLockInit + ConditionVariableInit pair (called once per phase).
   Borrow shape: lives inside the worker frame for the duration of the worker
   body; constructor is `unsafe` so the DSM-segment liveness contract is
   stated at one site per worker entry.

2. `ShmTocBuilder<'a>` — leader-side allocate + insert.
   - `unsafe fn new(toc: *mut shm_toc) -> Self`
   - safe `allocate<T>(key: u64, count: usize) -> *mut T` (or sized variant
     for byte-buffered allocations like the queue and graph image)
   - safe `insert<T>(key: u64, ptr: *mut T)`
   The DSM segment lifetime is contracted at `new`; subsequent operations
   are safe because they only forward to PG's bookkeeping for an
   already-validated toc.

3. `ShmTocReader<'a>` — worker-side attach + lookup.
   - `unsafe fn attach(toc: *mut shm_toc) -> Self`
   - safe `lookup<T>(key: u64) -> &'a T`
   - safe `lookup_mut<T>(key: u64) -> &'a mut T`
   - safe `lookup_required<T>(key: u64) -> &'a T` (panics-with-PG-error
     on null — supersedes the local `shm_toc_lookup_required` helper)
