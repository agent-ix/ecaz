## destroy() consumes the wrapper by value — nice ownership pattern

`ParallelContextRef::destroy(self)` taking `self` by value
prevents post-destroy reuse at the type system level. The
borrow checker enforces "no calls after destroy" without any
runtime cost. This is the kind of type-system-enforced contract
that Task 50 §Why named as the structural reduction goal:

> Structural reduction — encapsulation, type-lifted invariants,
> narrowed blocks, container-owned state, closure APIs — moves
> the contract into types and lets the borrow checker, not the
> reviewer, enforce it.

Strong design choice.

## Anti-pattern B / view-operations discipline — verified

ParallelContextRef has no `&Field` accessors. All accessors return
`Copy` pointer or scalar values:

- `as_ptr() -> *mut ParallelContext`
- `toc() -> *mut shm_toc`
- `seg() -> *mut dsm_segment`
- `nworkers_launched() -> i32`
- `worker(idx) -> *mut ParallelWorkerInfo`

`estimator_mut()` returns `*mut ParallelContextEstimator` via
`addr_of_mut!`, NOT a materialized `&mut`. That's important —
materialized `&mut` would be anti-pattern B.
