# Task 83 packet 001 — target-block rank diagnostic

## Decision

**Accept.** The bounded target-block-rank diagnostic gives us the
rank distribution we asked for in Task 82's review notes:
- 4,916 selected by global cap
- 81 ranked outside cap
- 3 not found in routed leaves

All 81 selected-leaf misses have `block_rank > 1152` and
`selected_by_global_cap=false`. This is the second-tier confirmation
the Task 82 attribution implied: the missed blocks aren't a small
ordering distance away — most are deep below the cap.

## Distribution refines the design space

| rank delta beyond cap | misses | share |
| --- | ---: | ---: |
| ≤ +128 | 7 | 8.6% |
| +129..+512 | 23 | 28.4% |
| +513..+2048 | 28 | 34.6% |
| > +2048 | 23 | 28.4% |

This is critical for whatever the next Task 83/84 slice picks:

- A "near-cap rescue" mechanism could only meaningfully address ~30 of
  the 81 misses (within +512), and only ~7 with a tight +128 window.
- The 51 misses farther than +512 need either a better selection score
  (better summary scoring → blocks rank higher) or a routing/leaf-side
  change that lets the cap not bind those blocks.
- A blanket cap increase to recover all 81 misses would need cap ≥
  3,200, which doubles candidates. Task 82 already rejected that path.
