## 2. Win at equal recall? NO — width=50 cut nothing, latency deltas are noise

Verified `remote_heap_candidate_sum` is **identical** between width 0 and width
50 in every single cell (e.g. 10k np8 5690/5690, all np≥16 6000/6000; 50k np8
5880/5880; 100k np8 5650/5650). Width 50 truncated **zero** candidates. The

`min(50, 10) = 10` never bit. There is no full-frontier ramp to collapse because
the "full" frontier was itself only 10.

Latency (profile total p50, release), verified from the tables:
