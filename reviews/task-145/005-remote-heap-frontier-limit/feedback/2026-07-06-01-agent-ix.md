## 4. What did `5819b313a` fix? A real frontier-width bug — verified from the diff

Root cause (confirmed by inspecting 004's counters): in
`remote_search_production_scan_heap_resolution_result_stream_impl`
(`scan_output.rs`), a single `top_k` value — the caller's `--top-k 10` override —
was used as **both** the final merge limit **and** the compact-candidate frontier
requested from every remote node. So each remote returned only 10 candidates
(`remote_heap_candidate_sum = 3 remotes × 10 × 200 queries = 6000`, exactly what
004 measured), and the packet-003 truncation `min(rerank_width, frontier) =
min(50, 10) = 10` could never fire. The 003 mechanism was structurally
un-testable at `top_k < rerank_width`.

The fix splits the two limits via a new pure helper
`production_scan_result_and_heap_frontier_limits(scan_candidate_limit,
top_k_override)`:

- `result_limit = top_k_override.unwrap_or(scan_candidate_limit)` — final merge
  and the `initial_remote_scan_threshold` still use this (correct: results merge
  to top_k).
- `heap_frontier_limit = scan_candidate_limit.max(result_limit)` — now used for
  the local heap resolution, the libpq dispatch plan, and
  `run_candidate_and_heap_receive_reusing_sessions` (the remote frontier). So
  each node now resolves the **wide scan frontier**, and `rerank_width` finally
  has something wider than `top_k` to cap.

Every `top_k → heap_frontier_limit` substitution in the diff is at a
frontier/dispatch site; every `top_k → result_limit` substitution is at a
merge/threshold/`==0`-guard site. The split is applied consistently and the
merge still correctly returns `result_limit`. This is a genuine correctness fix
to the 003/004 mechanism, exactly as the request describes ("reranking against
the wrong candidate set / frontier").

   and *raises* width=0 latency — so 004's numbers (0.9480 @ 100k np96, ~40 ms)
   are no longer the baseline. The re-A/B must re-establish both, and confirm
   width=50 holds the (new, higher-frontier) recall while cutting the rescore
   cost. This is where the 002 recall reconciliation finally becomes a real,
