  **end-to-end**") is therefore **not** demonstrated — the remote/distributed

- **No silent default flip.** Reloption default `EC_SPIRE_DEFAULT_RERANK_WIDTH`
  = 0 (full frontier, `mod.rs:184`); GUC `ec_spire.rerank_width` default = -1 =
  "use relation value" (`options/mod.rs:845`) → effective default = full. The
  packet's `full=0` baseline matches the production default, and it explicitly
  does not change defaults. Good — the win is not smuggled in via a default.
- **No over-truncation regression** observed, but width=50 safety is
  demonstrated **only** at this operating point (≤np96, these three shapes).
  Larger candidate surfaces / higher-recall regimes are unproven.
