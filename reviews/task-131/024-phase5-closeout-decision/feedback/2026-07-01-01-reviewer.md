## Accepted decisions

- **Global merge before heap → shelve / do not promote.** Correct and

  original 005–009 packets: all five cells match to the digit (recall,

- **Candidate-to-heap streaming → iterate / keep as structural behavior.**

  as enabling infrastructure — not claiming a product win — is the right call.
- **The one transferable finding is stated honestly** — compact remote

  and it did *not* justify the explicit-subset heap endpoint. Agreed.

## NOT accepted: Phase 3 "shelve for the current default surface"

The closeout rejects Phase 3 on `sound_bound_available_sum=0`. Independent code
trace (see packet 023 feedback) shows that zero is a **build-config artifact**,
not a property of the algorithm or the surface:

- The sound-bound source (leaf block summaries) is fully wired end to end and
  scored at the *sound* radius_weight 1.0. It reports zero solely because the
  representative indexes were built with `ec_spire.leaf_block_rows = 0` (the
  default), so no summaries were ever persisted. An index built that way
  **must** report `available=0` by construction.
- Therefore Phase 3's early-stop was never actually exercised. It was measured
  against indexes structurally incapable of producing the bound, then declared
  unavailable. That does not support a shelve.
- This is the phase that matters most: Phase 1 proved the latency bottleneck is
  remote scan/scoring, and Phase 3 is the only phase that targets scan work.
  Shelving it on a GUC technicality shelves the single idea aimed at the real
  bottleneck.

Packet 023 itself names the correct next step ("build representative indexes
with leaf block summaries enabled … measure available / selective / storage /
recall"). That run is **one rebuild away**, not a new subsystem, and it must
happen before the shelve. Concretely: rebuild one 10k or 50k `n128/b4` cell with
`ec_spire.leaf_block_rows = 64` (GUC consumed at build time — rebuild required),
re-run the threshold boundability profile, and read available / block-skip /
row-skip / storage-delta / recall. Only then is there evidence to
promote, iterate, or shelve Phase 3.
