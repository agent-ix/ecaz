## Why this matters for Tasks 93–98

When `sve::score_block32_sve` stops delegating and becomes a real SVE2
kernel that returns `Isa::Sve2`, the existing counter pipeline will
record `isa=sve2` automatically. No further wiring is required in the
common counter surface — the Task 99 cross-(AM × quant × ISA) matrix
will see correct ISA attribution as soon as a real kernel ships.

If `current_isa()` ever returns an ISA whose backend stub still
delegates to scalar (the current state for `Avx2`, `Neon`, `Sve`,
`Sve2`), the counter still says `isa=scalar` because the backend's
returned `Isa` is what gets recorded, not the dispatched `current_isa()`
value. That is the intentional behavior — fallback stubs honestly
identify as scalar.
