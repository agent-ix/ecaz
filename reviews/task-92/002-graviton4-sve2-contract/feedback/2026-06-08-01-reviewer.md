  across vector lengths." ✓

## Smaller observation (non-blocking)

The current ADR wording in the production-target paragraph still includes
`sve-256` as an alternative example after the "Inference from host class
alone is forbidden" line. That's defensible (it shows the
measured-verbatim notation for a different runtime width) but a future
reader could misread it as a contradicting example. Consider tightening
in a later packet to "for example `sve2-128`; on a host that measures a
different runtime width, report that measured width verbatim instead."
Not blocking.
