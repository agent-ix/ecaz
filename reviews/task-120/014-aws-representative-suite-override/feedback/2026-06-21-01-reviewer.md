## Runner discipline — PASS

`bench.sh` is the pre-existing SPIRE-AWS wrapper that renders a checked-in suite
JSON (with `jq`) and invokes `ecaz bench suite run --config ... --manifest-output
... --results-output ...` (`bench.sh:77-81`). This change does **not** introduce
a bash sweeper; it adds three env defaults that select *which checked-in suite
JSON* the existing wrapper renders. The execution path remains `ecaz bench suite
run`. The override default-falls-through to the canonical representative suite
when the env-vars are unset, so the normal path is unchanged. This respects the
"`ecaz bench suite` only" rule.

Override composition is sound: each env-var maps 1:1 to a single tier's suite
path and has no effect on the other tiers, the `correctness`/`stress` tiers, or
any other lane. No accidental clobber.

`render-override/suite-representative-priority.json`) are a **distributed-SPIRE
representative harness** — `ec_spire` profile, `sweep:[64]`, a 1M `repr` prefix,

to flag.
