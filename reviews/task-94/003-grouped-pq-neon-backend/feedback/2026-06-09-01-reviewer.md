Matches ADR-076 dispatch contract. ✓

### Bit-exact accumulation order

`score_block32_neon_impl` (neon.rs:47-73) loops `lane_base in (0..32).step_by(4)`
outer / `group_index in 0..group_count` inner. Each iteration builds
`[f32; 4]` from scalar LUT lookups (one per lane), loads with
`vld1q_f32`, adds to accumulator with `vaddq_f32`.

Per-lane sum order: `acc = 0; for g in 0..G { acc += lut[g*16 + idx_g] }; store`.
Identical to `(0..group_count).map(...).sum::<f32>()` left-fold from 0.0
in `grouped_pq_score_f32`. Bit-exact parity holds. ✓

The scalar-lane gather into `[f32; 4]` before `vld1q_f32` is the
Phase 1-approved "scalar lane gather acceptable for first NEON landing"
path. ✓

### Test scaffolding

`mod.rs:124-132` exposes `score_grouped_pq_block32_neon_for_test` which
returns `Option<Isa>`. The conditional parity test
`grouped_pq_neon_backend_matches_scalar_reference_bits_when_available`
asserts `Isa::Neon` only on NEON-capable hosts; on x86 it returns early.

The general `grouped_pq_block32_matches_scalar_reference_bits_across_shapes`
