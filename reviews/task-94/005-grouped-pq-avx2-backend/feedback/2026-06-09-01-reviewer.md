### Bit-exact accumulation

`score_block32_avx2_impl` (avx2.rs:59-89):

```text
for lane_base in (0..32).step_by(8):
    acc = _mm256_setzero_ps()
    for group in 0..G:
        indices[0..8] = lut_offset_g + nibble_decode(codes[lane_base+i])
        idx_vec = _mm256_loadu_si256(&indices)
        vals = _mm256_i32gather_ps(lut.as_ptr(), idx_vec, 4)
        acc = _mm256_add_ps(acc, vals)
    _mm256_storeu_ps(out[lane_base], acc)
```

Per-lane sum order: `acc[lane_offset] = 0; for g { acc += lut[g*16 + idx_g] }; store`.
Identical to `(0..group_count).map().sum::<f32>()` left-fold. Bit-exact
parity holds per lane. ✓

`_mm256_i32gather_ps` with `scale=4` against `lut.as_ptr()` reads the
same memory bytes as scalar `lut[index]` — no precision delta. ✓

### `lut_index` helper

`avx2.rs:91-101` produces `i32` indices via:

```rust
let centroid = if g & 1 == 0 { packed & 0x0F } else { packed >> 4 } as usize;
```
