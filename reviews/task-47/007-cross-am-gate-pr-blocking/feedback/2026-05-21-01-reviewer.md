**2. Threshold enforcement is real.**

`crates/ecaz-cli/src/commands/bench/suite.rs` line 671-672:

```rust
if failures > 0 {
    bail!("suite thresholds failed: {failures}");
}
```

`bail!` returns `Err`, which propagates to the binary's exit
code (anyhow → process exit 1). CI step fails non-zero → CI job
fails. Real PR-blocking, not just reporting.

**3. Fixture has 4 thresholds.**

`fixtures/gates/cross-am-gate-small.json`:
- HNSW recall floor 0.84 (recall@k ≥ 0.84)
- DiskANN recall floor 0.55 (recall@k ≥ 0.55)
- HNSW~DiskANN Jaccard floor 0.1 (consistency report-floor)
- HNSW~DiskANN Kendall-tau ≥ -1.0 (degenerate range check)

The Jaccard floor (0.1) is *very* loose — almost any consistent
output passes it. That's a "alert if hugely divergent" gate, not
a tight consistency lock. **Worth tightening in a follow-up
packet** once baseline cross-AM Jaccard values are known on
real corpora.

The Kendall-tau floor at -1.0 is a no-op (always passes). It's
there as a "field exists in output" sanity check. Fine for now.

## Findings

### 1. The PR-blocking promotion is the right call

Cross-AM consistency catches a class of bugs that recall and
cost don't:
- A tie-breaking change that flips top-k order without changing
  membership — recall stays the same, Jaccard drops.
- A SIMD bug that produces consistent-but-wrong scores across
  AMs — both AMs degrade the same way, recall stays high, but
  cross-AM Jaccard against the brute-force baseline drops.

Promoting cross-am-gate to PR-blocking closes one of the
documented Task 47 exit-criteria gaps. Real correctness work.

### 2. The Jaccard threshold is intentionally loose — tighten later

0.1 Jaccard is essentially "don't completely disagree." A typical
HNSW vs DiskANN top-10 should easily score 0.5+. The loose floor
catches catastrophic regressions but not subtle ones.

This is the right shape for an *initial* gate — false positives
are worse than weak detection at first. After running on real
corpora for a few weeks, tighten the floor to the observed
baseline minus a documented tolerance.

Not blocking. Worth a follow-up note in `docs/recall-floors.md`
that says "tighten cross-AM Jaccard floor once N weeks of
baseline data are available."
