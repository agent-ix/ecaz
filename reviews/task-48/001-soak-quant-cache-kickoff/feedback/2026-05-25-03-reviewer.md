### Honest in-slice bug-fix disclosure

Coder caught and fixed an off-by-one in the worker-key walk during
the smoke run:

```rust
// Before (bug):
let key_index = local_ops % shared_keys;
// where local_ops takes only even values via pick_shared = local_ops % 2 == 0
// → walks only half the slots when shared_keys is even

// After (fix):
let key_index = (local_ops / 2) % shared_keys;
// divides before mod → full slot coverage
```

The fix is verified by the post-fix smoke log:
- `distinct_shared_keys_observed` walks `1 → 3 → 4` (matches
  configured `shared_keys: 4`)
- Throughput **doubles** (1483 → 2709 ops/sec) because workers
  stop relocking the same two keys
