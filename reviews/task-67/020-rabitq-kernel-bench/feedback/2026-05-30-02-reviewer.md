- N1 (mixed code+measurement packet). Still applies; per NFR-007,
  follow-up benchmarking on this kernel matrix should land under
  `benchmarks/rabitq-kernel/` once stable. Not a blocker.
- N2 (cross-backend divergence check). Checksums between scalar and
  auto AVX-512 differ at the 5th–6th decimal
  (`bits1 single-scalar`: 2.677587 scalar vs 2.677600 auto;
  `bits4 batch`: -61.663651 vs -61.663654). Differences are at f32

  order. A future enhancement could compute and emit
  `abs(auto - scalar)` as an explicit divergence column to make this
  in-band rather than requiring a manual diff — not needed to land
  this packet.

  because the bench is the entrypoint; flag with a comment if reused
  in-process.

  records only `backend`, `dim`, `candidates`, `iterations`. Host
  attribution lives in `manifest.md` / S3 path / `cpu-features.log`.
  Acceptable; consider adding host model + kernel to the log preamble
  in a future kernel-bench change.
- N5 (zero-byte preflight logs). Acknowledged in `manifest.md`:
  `cloud-install-5df1308d4.log` and the older `cloud-resume.log` are
  zero bytes, with the durable install evidence being the successful
  post-install AWS suite execution. Fine for this packet; consider
  fixing the underlying `cloud install --log-file` flush behavior in
  a separate change so future packets do not need a written
  workaround.
- N6 (interpretation framing). `request.md` correctly distinguishes
  kernel-level wins from the packet 017 SQL wall-time gap and does
  not overclaim Task 67 completion. Good.
