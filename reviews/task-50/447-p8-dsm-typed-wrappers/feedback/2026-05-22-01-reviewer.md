# Approve: P8 typed DSM/atomic/SpinLock/CondVar wrappers — opens the build_parallel.rs door

## Verified by reading the diff

`git show ab09c2a07` reviewed in full. New module
`src/am/common/dsm.rs` (156 lines) lands plan 030 §P8's contract goal:
"typed shared-memory layouts where each field wrapper names its
memory-ordering and lock invariant."

Module surface:

- `PgAtomicU32Ref<'a>`: lifetime-bound wrapper over
  `pg_atomic_uint32`. `unsafe fn from_raw` is the **only unsafe
  surface**; `load_acquire` / `store_release` /
  `compare_exchange_acqrel_acquire` are safe and call PG's atomic
  primitives. `Send + Sync` impls are justified — PG atomics are
  designed for cross-thread access through these exact primitives.
- `SpinLockGuard<'a>`: RAII guard with Drop-on-release. `unsafe fn
  acquire` is the only unsafe surface; lifetime ties the guard to
  the protected DSM field.
- `ConditionVariableRef<'a>`: same pattern over `signal()`.
- `spinlock_init` / `condition_variable_init`: one-shot in-place
  init helpers.

## First migration — `PgLockedDsmInsertStateCell`

The wrapper is consumed in the right place: HNSW
`PgLockedDsmInsertStateCell` collapses three internal `unsafe`
blocks (read_u32 / write_membarrier / compare_exchange) into a
single `as_atomic_ref()` borrow, saving 2 unsafe blocks at the call
site. The SpinLockGuard / ConditionVariableRef wrappers are landed
but not yet consumed by the wide compound spinlock blocks —
deferring is the correct narrower-count choice for now.

lever. The compound `SpinLockAcquire / record_worker_counts /
SpinLockRelease + ConditionVariableSignal` blocks in
`build_parallel.rs` worker_main and graph_worker_main collapse

```rust
{
    let _guard = unsafe { SpinLockGuard::acquire(&mut (*shared).mutex) };
```

out once the surrounding `&mut (*shared)` access pattern is migrated
