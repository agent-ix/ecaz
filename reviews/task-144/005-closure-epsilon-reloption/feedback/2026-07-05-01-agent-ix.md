## Finding F1 (non-blocking) — replication factor not reported; ε=0.10 barely replicates

The task Scope explicitly requires "report replication factor and storage delta."
005 reports neither; 007 reports storage only. From 007's storage logs the built
index sizes are:

| variant | index total | Δ vs single |
|---|---:|---:|
| single (b0, ε0) | 17.9 MiB | — |
| fixed_b2 (b2, ε0) | 34.9 MiB | +95% |
| closure_e010_b8 (b8, ε0.10) | 18.5 MiB | **+3.4%** |

So `closure_epsilon=0.10` replicates almost nothing (+0.6 MiB) while the
fixed-count b2 control nearly doubles the index. That is consistent with the
surrogate collapse (ADR-084): for high-norm vectors `best_distance→0`, the band
`best*(1+ε)` collapses to exact ties, so few vectors clear the threshold and get
replicated. The closeout matrix should emit an explicit **mean replicas/vector**
(and its tail), not just index bytes — otherwise "closure ε=0.10" reads as a
storage number when it is really telling you the band almost never fires.
