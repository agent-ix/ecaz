# Task 87 Packet 015 — Approve Closeout

## Verdict

**Approve closeout. Task 87 closes complete.**

The work shipped within the scope established by packet 009's
walk-back: `CandidateBatch` data-flow abstraction + per-AM batch
routing on existing per-AM codec surfaces, with the cross-AM
`QuantCodec` migration handed to Task 91 and DiskANN handed off via
Stop Condition packet 005.

The completion audit is honest about which gates were met fully,
which were met partially, and which are explicitly not claimed.
That honesty is the right posture for closing this task.

## What's actually proven

- **Recall byte-equal at every measured off/on cell** across SPIRE,
  IVF, HNSW × real10k/50k/100k. The strictest correctness gate
  passes. ✓
- **Storage unchanged.** Off/on flips a session GUC against the
  same index surface. By construction. ✓
- **SPIRE end-to-end pipeline gains** of −28.6% to −37.8% across
  p50/p95/p99 on every corpus size. This is the strongest evidence
  that `CandidateBatch` plumbing is worth its weight even without
  new block kernels.
- **HNSW recall-preserving** with modest gains; real50k shows real
  wins (p95 −10.0%, p99 −28.4%). real10k/100k smaller wins
  consistent with per-frontier batches being small under
  graph-traversal-dominated wall time.
- **IVF recall-preserving on TurboQuant cells**: real10k and
  real100k clean wins; real50k cell is on a RaBitQ surface (not
  Task 87's batch route — see packet 013 feedback) and should be
  annotated as a surface-format artifact rather than a gate miss.
- **DiskANN closed correctly** by accepted Stop Condition (packet
  005) + Task 91 handoff (packet 009).

## Explicitly not claimed (and that's OK)

- The original "≥ 2× scoring-share per AM" gate from the task file
  is **not met** on any AM. It is also not directly measurable on
  HNSW/IVF with current instrumentation. SPIRE end-to-end suggests
  the kernel share moved meaningfully but cannot be isolated from
  pipeline gains.
- "End-to-end p50/p95/p99 improves at every cell" is met for SPIRE
  and IVF-TurboQuant. HNSW real100k p50 is flat. IVF real50k is
  RaBitQ (not Task 87's path).

Both of these gates were written when Task 87 was expected to land
a new block kernel (the 32-vector u8 nibble LUT discussed in
Phase 1 design). The Phase 1 design call was to defer that kernel,
and the packet 001 blocker B4 structural-slice carve-out followed
from that. With no new kernel, the universal 2× gate was always
going to need a carve-out at closeout — and the closeout applies
exactly that carve-out, transparently.

The carve-out is sound: the architectural plumbing is the value
Task 87 ships; future kernel work and Task 91's codec migration
will be the vehicles for the next perf step.
