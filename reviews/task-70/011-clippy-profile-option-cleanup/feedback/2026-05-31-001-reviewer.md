# Review: Task 70 / Packet 011 — Clippy Profile Option Cleanup — ACCEPT

Reviewed `1c0de8436a3d800d2d68a1166d4fe6e08691a4ba`. Pure mechanical
replacement of `Option::as_deref_mut()` with `Option::as_mut()` across
~10 call sites in the frontier-profile plumbing.

## What this packet does

Closes the Task 70 exit-criterion clippy gate
(`cargo clippy --all-targets --no-default-features --features pg18 --
-D warnings`). The packet 008 instrumentation used
`frontier_profile.as_deref_mut()` to project `Option<&mut FrontierProfile>`
through `DerefMut`; clippy flagged this with `needless_option_as_deref`
because `as_mut()` is the more direct form on this type shape.

## What I verified

- **Both forms compile and the semantics are equivalent.**
  `Option<&mut T>::as_deref_mut()` returns `Option<&mut T>` (deref'd
  through `&mut T`'s `DerefMut` impl). `Option<&mut T>::as_mut()`
  returns `Option<&mut &mut T>`. Field access on the matched
  `profile` auto-derefs in either case, so `profile.candidate_heap_us`
  and `&mut profile.candidate_heap_us` work identically. Behavior is
  bit-for-bit unchanged.
- **No production behavior touched.** Only the option-projection
  call sites changed; the wrapped operations (Instant timing,
  counter increments) are identical.
- **Tests pass.** 20/20 in the scan module.
- **Clippy gate now clean** per `cargo-clippy-pg18.log`.

## Verdict

Accept. Trivial cleanup that closes the clippy exit-criterion gate.
No further concerns.
