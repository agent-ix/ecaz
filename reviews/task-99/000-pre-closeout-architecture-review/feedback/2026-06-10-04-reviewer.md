# F9 (new finding) + operator decision — lut32 has no real SIMD kernel on any ISA

## F9 — Flagship-lane kernel gap, previously unowned

Verified 2026-06-10: `src/quant/lut32/{neon,sve,avx2}.rs` are 11-line
scalar-delegating stubs. The lut32 family — TurboQuant no-QJL 4-bit at
dim 1536, the canonical production lane and the storage format of
every standard DBpedia fixture — has **no real SIMD block kernel on
any ISA**. Its measured "kernel" effects since Task 87 are
batch-amortization only. Consequences if unaddressed:

- every lut32 counter row on Graviton 4 reads `isa=scalar`;
- Task 101's sub-width backport would dispatch lut32 tails into
  scalar stubs;
- Task 99's matrix would carry `missing_kernel` on the flagship lane
  while every secondary lane has real kernels.

Ownership history: Task 92 backfilled the module layout with stubs
and deferred G4 evidence to "the first real SVE2 backend" from Tasks
93–98 — each of which built a different quant family. No task ever
owned lut32's own SIMD backends.

## Operator decision (2026-06-10)

Option (a) selected: build the kernels, in-epic. **Task 102 created**
(`plan/tasks/102-lut32-simd-block-kernels.md`): AVX2 + NEON + SVE2
lut32 kernels, candidate-parallel shape, register-resident LUT
(shuffle/tbl, sharing the Task 94 F8 approach — F8's measurement
showed gather-based LUT kernels run ~1.1× scalar, so gather is ruled
out from the start), octet/partial entry points compatible with the
Task 101 driver, standard-fixture evidence with the established
ladder gates.

Additionally pinned in the Task 99 task file: the complete
index × quant × mode profile must include a **Graviton 4 lane** (the
ADR-025 reevaluation hinges on Graviton L1D behavior; Intel-only
would be vacuous for that decision).

## Final G4 sequencing (supersedes prior orderings)

Task 101 (driver) + Task 94 F8 (grouped-PQ repack incl. SVE2 tbl) +
Task 102 (lut32 kernels) → then the Task 94/97 G4 runbooks and the
Task 99 G4 profile, so ARM evidence is collected once against
final-shape kernels for every family including the flagship.
