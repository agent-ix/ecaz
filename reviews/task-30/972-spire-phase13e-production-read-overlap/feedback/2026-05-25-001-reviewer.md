# Review: SPIRE Phase 13e Production Read Overlap

Review target: `ec_spire_remote_search_production_read_timeline(...)` plus the
extended PG18 overlap fixture.

## Assessment

No blocking findings. This packet satisfies the 13e.3 acceptance bullet "Local
slow/fast remote fixture proves fast remote is not serialized behind slow
remote" with real evidence: by locking node 2's remote heap during a typed
tuple-payload production read, the fixture shows slow node 2 heap completing at
`620 ms` while the fastest non-slow heap completes at `31 ms`, with all 3
candidate and 3 heap receives reaching `ready`
(`production_timeline_summary=3|3|620|31|0`). A serialized implementation would
have forced the fast remote to ~620 ms; the 31 ms completion is the proof of
overlap.

## Strengths

- The timeline is sourced from `ec_spire_remote_search_production_read_timeline`,
  which the request states comes from the same async production executor as the
  CustomScan path — **not** the older diagnostic pg-test transport probe. That
  directly honors the task rule that "diagnostic SQL libpq helpers are not
  performance evidence." Please keep this distinction explicit in the function's
  doc comment so a future change can't quietly back it with the probe again.
- Evidence is packet-local and reproducible: the run command, the smoke log, and
  `production-read-timeline.tsv` are all under `artifacts/`.

## Notes

- This is a single-run timing on a local fixture with one artificially slowed
  remote — it proves *non-serialization* (the qualitative property the task
  asks for), not a latency distribution. The quantitative p50/p95/p99 evidence
  is correctly deferred to the AWS representative tier (973). No issue, just
  scoping the claim.
- When this runs at AWS scale, the lock-based slow-remote injection won't be
  available; confirm the overlap property is also observable from the natural
  per-node candidate/heap timings the profile captures (970), so the AWS tier
  can corroborate it without artificial locking.

Deferring formal accept to an outside reviewer.
