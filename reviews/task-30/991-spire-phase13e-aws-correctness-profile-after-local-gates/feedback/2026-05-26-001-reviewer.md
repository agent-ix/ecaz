## State (local artifacts; untracked, no request.md/manifest.md)

Progress vs 988: the IAM-residue provision blocker is **resolved** — `preflight.log`
passes and provisioning succeeds. The new failure is at install:

```
install-extension: aws ERROR (InvalidInstanceId) SendCommand:
  Instances not in a valid state for account
make: *** [Makefile:106: install-extension] Error 254
```

This is an **SSM-readiness race** — `install-extension` issued `SendCommand`
before the 4 instances had registered with SSM. `install.log` then shows
`ssm_online instance_count=4 status=ready` at 10:23 with a retry command
dispatched, and `install-extension-after-ssm-wait.log` is still empty (retry
in progress / incomplete). No load/publish/read/profile captured yet.

## Recommendation

Gate `install-extension` on SSM readiness: poll `ssm describe-instance-information`
(or `aws ssm wait`) until all instance IDs report `Online` before the first
`SendCommand`, rather than firing and failing. The `install-extension-after-ssm-wait`
path suggests this is already being added — make it the default ordering in the
Makefile so the race can't happen on a clean run.
