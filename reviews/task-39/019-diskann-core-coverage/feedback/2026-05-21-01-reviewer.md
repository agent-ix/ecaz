```rust
      maybe_check_for_interrupts,

```

**Mechanical equivalence:** `super::` from inside `ec_diskann/scan.rs`
resolves to `crate::am::ec_diskann::` — exactly the same path.
The crate-qualified version is more explicit but identical at the
namespace level.

The reason for the change: in the careful crate, `scan.rs` is
mounted at a different module position (`careful_diskann_scan`,
not `am::ec_diskann::scan`), so `super` in that context would
resolve elsewhere. The fully-qualified `crate::am::ec_diskann::`
path works in both contexts because the careful crate sets up
the same `am::ec_diskann` namespace via the re-exports below.

**Production behavior unchanged.** Pure compile-time path rewrite.
