## The breakthrough mechanism

The packet 042 attribution chain established that the bottleneck
was fixed object_bytes_sum of **14.97 GB** decoded per query
regardless of block cap. The deferred decode change collapses that:

- **Before**: load all 19,200 routed leaves' assignment segments
  (14.97 GB decoded) → score summaries → select global blocks →
  scan selected row ranges (only 3.88M candidates anyway)
- **After**: load only summary segments → score summaries →
  select global row ranges → decode only the assignment segments
  intersecting those selected ranges

The 14.97 GB upfront decode was wasted work — most of those bytes
were for rows that got pruned by global block selection. Deferred
decode skips them entirely.
