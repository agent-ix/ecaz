**Accept as honest negative experiment.** Endpoint-pair
representatives (farthest pair instead of cluster means) collapse
recall by 6-9pp vs packet 029's cluster-mean k=2. The hypothesis

Source change correctly reverted. Cluster-mean k=2 stays as the

## Why endpoints fail

The packet's interpretation is correct: endpoints "over-rank
block extremes and lose the stable block-level signal." A
farthest-pair endpoint can score very high (or very low) by
chance against any given query, dominating the block's summary
score even when the block as a whole has mediocre top-10
relevance.

Cluster means average out individual row noise; endpoints
amplify it. For block-level winnership (which is the actual
ranking goal), the averaging property is essential.

## What's solid in the experiment design

- Local-only experiment, source reverted, no upstream change.
- Same suite shape as packet 029 for direct comparison.
- Patch file checked in (`endpoint-representative-source-diff.patch`)
  so the experiment is reproducible.
- Three caps tested across the same range as 029.

That's a clean negative-result methodology — the kind of
experiment that's worth running fast and abandoning fast.
