## Test design — sound

Stresses the `OnceLock<Mutex<HashMap<_, Arc<_>>>>` cache backing
`ProdQuantizer::cached`/`cached_with_presence`:

- 4 worker threads via `thread::scope`
- Each requests one shared key + one private key (distinctive seed
  namespaces `0xCAFE_BABE_FACE_FEED` and `0xA5A5_5A5A_C3C3_3C3C ^ wid`)
- Asserts:
  - All 4 shared-key Arcs satisfy `Arc::ptr_eq` (canonical init won
    the race)
  - Every private-key Arc is distinct (`Arc::ptr_eq` returns false)
- Tests three layered primitives in one shot: `OnceLock::get_or_init`,
  `Mutex::lock`, `HashMap::entry(...).or_insert_with(Arc::new)`

Distinctive seed namespaces correctly avoid collision with other
in-process tests populating the global cache.
