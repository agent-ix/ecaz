## Wrapper design — sound

Spot-checked the new surface:

- `WalTxnScope<'rel>` correctly encodes relation liveness via
  `PhantomData<&'rel ()>`. Two constructors `start` (unsafe raw-ptr)
  + `start_handle` (safe `RelationHandle`) lets call sites graduate
  to the safe variant when they hold a handle. Good ratchet design.
- `RegisteredBufferPage::add_item` returning
  `Result<OffsetNumber, PageAddItemError>` replaces the open-coded
  `if offset == InvalidOffsetNumber { pgrx::error!(...) }` pattern
  cleanly. `PageAddItemError { block_number }` carries the diag
  context without holding `&self.buffer` across the move.
- `LockedBufferGuard::read_main_handle` /
  `read_main_locked_handle` mirror the existing pointer variants
  with the safe `RelationHandle` input — exactly the handle-ratchet
  pattern established by Task 41.
- All new wrappers `#[allow(dead_code)]` scoped to "Consumed by HNSW
  migration in Task 54 packets 003/004" — that attribute MUST come
  off in slice 003/004; flag if it lingers in closeout.
